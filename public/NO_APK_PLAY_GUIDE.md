# The Unknown Universes — Game Collections No-APK Play Guide

This guide explains how to easily run, share, and play **The Unknown Universes** game collections on any device (PC, Mac, Linux, iOS, Android, and consoles) **without needing an Android APK**.

---

## 1. Instant Browser Play (No Installation Required)
When you export a portable game package from the app (`Export & Compat` menu):
1. Save the file as **`index.html`**.
2. Double-click **`index.html`** or drag and drop it into any modern web browser (Google Chrome, Apple Safari, Microsoft Edge, or Mozilla Firefox).
3. The game runs instantly offline with full canvas rendering, touch controls, audio tracks, and gamepad support.

---

## 2. Free Cloud Hosting via GitHub Pages / Vercel
To share your custom game collections online with friends:
1. Create a free public repository on **GitHub** (e.g., `unknown-universes-collection`).
2. Upload your exported **`index.html`** file to the root of the repository.
3. Go to your repository **Settings > Pages**, select the `main` branch root folder, and click **Save**.
4. GitHub will give you a live URL (e.g., `https://yourusername.github.io/repo-name/`) where anyone can play instantly in their browser!

---

## 3. Windows Desktop Executable (.hta) or Progressive Web App (PWA)
* **Windows Native App (.hta):** Rename **`index.html`** to **`game.hta`**. Double-click it on Windows to run it inside a standalone desktop application frame without browser tabs.
* **Progressive Web App (PWA):** Open `index.html` in Chrome or Edge, click the browser menu (⋮), and select **"Install The Unknown Universes"** to add it to your desktop or phone home screen.

---

## 4. Console & Controller Support
* Connect any Bluetooth or USB gamepad (Xbox Series X, PlayStation DualSense, Nintendo Switch Pro).
* The W3C Gamepad API automatically maps buttons and analog sticks for authentic console-grade control.
